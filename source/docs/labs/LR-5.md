# Лабораторная №5: Регрессия с применением Scikit-Learn

## Цель работы

Целью работы являлось построение модели машинного обучения для прогнозирования стоимости недвижимости на основе характеристик объектов недвижимости и сравнение качества различных алгоритмов регрессии.


## Подготовка данных

В ходе работы был проведён анализ датасета, содержащего характеристики жилой недвижимости. Для обучения моделей данные были разделены на:

- признаки (характеристики недвижимости);
- целевую переменную (стоимость недвижимости).

После подготовки данных были обучены модели машинного обучения для решения задачи регрессии.


## Исследуемые модели

В работе были рассмотрены следующие модели:

1. Linear Regression
2. Random Forest Regressor
3. Random Forest Regressor с изменёнными гиперпараметрами
4. Gradient Boosting Regressor


## Анализ важности признаков

Для определения влияния признаков на качество предсказания использовалась модель Random Forest.

### Наиболее значимые признаки

- Жилая площадь
- Оценка риелтора
- Широта
- Долгота
- Год постройки

### Наименее значимые признаки

- Год реновации
- Вид на воду
- Просмотрены ранее
- Спальни

Для дальнейшего эксперимента были удалены наименее значимые признаки.


## Исследование гиперпараметров Random Forest

Для улучшения качества модели были исследованы гиперпараметры алгоритма Random Forest.

Использовалась следующая конфигурация:

```python
RandomForestRegressor(
    n_estimators=500,
    max_depth=20,
    min_samples_split=5,
    min_samples_leaf=2,
    random_state=42,
    n_jobs=-1
)
```

После обучения модель была протестирована на тестовой выборке и сравнена с другими алгоритмами.


## Результаты экспериментов

| Модель | MAE | RMSE |
|---------|---------:|---------:|
| Random Forest (базовый) | 70761.90 | 136496.84 |
| Random Forest (улучшенный) | 74973.44 | 150899.34 |
| Gradient Boosting | 75950.56 | 151171.15 |
| Linear Regression | 126852.51 | 201883.24 |


## Анализ результатов

По результатам экспериментов лучшей моделью оказалась базовая модель Random Forest Regressor.

Показатели качества:

- MAE = 70761.90
- RMSE = 136496.84

Несмотря на проведённую настройку гиперпараметров, улучшенная версия Random Forest показала более высокую ошибку по сравнению с базовой моделью. Модель Gradient Boosting также уступила базовому Random Forest.

Модель линейной регрессии показала наихудший результат среди рассмотренных алгоритмов.

# Интеграция модели в веб-сервис FastAPI

Для использования обученной модели в веб-приложении необходимо выполнить следующие шаги:

1. Обучить модель машинного обучения.
2. Сохранить модель в файл с помощью библиотеки Joblib.
3. Создать приложение FastAPI.
4. Загрузить модель при запуске сервиса.
5. Описать входные данные через Pydantic.
6. Создать API-метод `/predict`.
7. Принимать характеристики объекта недвижимости от пользователя.
8. Формировать вектор признаков.
9. Выполнять предсказание с помощью метода `predict()`.
10. Возвращать результат в формате JSON.
11. Развернуть приложение на сервере или в облачной инфраструктуре.

Пример сохранения модели:

```python
import joblib

joblib.dump(model, "house_price_model.pkl")
```
