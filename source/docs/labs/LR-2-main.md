# Лабораторная работа 2: Основы NumPy

## Цель работы
Освоить основные возможности библиотеки NumPy для численных вычислений и анализа данных, научиться работать с массивами, выполнять векторные и матричные операции, проводить статистический анализ и визуализировать данные.

## Задание
Реализовать набор функций для работы с массивами NumPy, включая:
1. Создание и преобразование массивов
2. Векторные операции (сложение, умножение на скаляр, скалярное произведение)
3. Матричные операции (умножение, определитель, обратная матрица, решение СЛАУ)
4. Статистический анализ данных
5. Визуализация результатов

## Ход выполнения

### 1. Создание и обработка массивов

**Функция `create_vector()`**:
- Использует `np.arange(10)` для создания вектора от 0 до 9
- Возвращает массив формы (10,)

**Функция `create_matrix()`**:
- Использует `np.random.rand(5, 5)` для создания матрицы 5x5 со случайными числами
- Значения равномерно распределены в интервале [0, 1)

**Функция `reshape_vector()`**:
- Преобразует вектор (10,) в матрицу (2, 5) с помощью `reshape()`
- Добавлена проверка входной формы для надежности

**Функция `transpose_matrix()`**:
- Использует `.T` для транспонирования матрицы

### 2. Векторные операции

**Функция `vector_add()`**:
- Реализует поэлементное сложение через оператор `+`
- Добавлена проверка совпадения форм

**Функция `scalar_multiply()`**:
- Умножение вектора на число через оператор `*`

**Функция `elementwise_multiply()`**:
- Поэлементное умножение через оператор `*`
- Проверка совпадения форм

**Функция `dot_product()`**:
- Скалярное произведение через `np.dot()`
- Результат приводится к типу float

### 3. Матричные операции

**Функция `matrix_multiply()`**:
- Умножение матриц через оператор `@`
- Проверка согласованности размерностей

**Функция `matrix_determinant()`**:
- Вычисление определителя через `np.linalg.det()`
- Проверка, что матрица квадратная

**Функция `matrix_inverse()`**:
- Вычисление обратной матрицы через `np.linalg.inv()`
- Проверка на вырожденность (det ≠ 0)

**Функция `solve_linear_system()`**:
- Решение СЛАУ через `np.linalg.solve()`
- Проверка корректности размерностей

### 4. Статистический анализ

**Функция `load_dataset()`**:
- Загрузка CSV через pandas
- Преобразование в numpy массив

**Функция `statistical_analysis()`**:
- Вычисление основных статистических показателей:
  - Среднее арифметическое (`np.mean`)
  - Медиана (`np.median`)
  - Стандартное отклонение (`np.std`)
  - Минимум/максимум (`np.min`/`np.max`)
  - Перцентили (`np.percentile`)

**Функция `normalize_data()`**:
- Min-Max нормализация по формуле (x - min)/(max - min)
- Обработка граничных случаев

### 5. Визуализация

**Функция `plot_histogram()`**:
- Гистограмма распределения оценок
- Настройка внешнего вида и сохранение

**Функция `plot_heatmap()`**:
- Тепловая карта корреляции предметов
- Использование seaborn для красоты

**Функция `plot_line()`**:
- График зависимости оценок от номера студента
- Линейный график с маркерами
